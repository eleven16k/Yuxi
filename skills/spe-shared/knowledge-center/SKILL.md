# 知识中心

用户想打开知识中心、查知识时：

1. 先调 `kb_list`（不传参数 = 官方 + 本租户合并列表），出 panel 面板卡：记录ID/标题/分类/来源/更新时间/作者。面板顶部过滤框可本地筛「官方」「本租户」「分类」。
2. 用户要看某篇正文：把该行「记录ID」传给 `kb_read`，出长文卡（来源徽标：官方=平台共享，本租户=租户私有）。
3. 回答业务问题需要依据时，优先检索知识中心（`kb_list` 的 q/category 过滤 + `kb_read` 取原文），引用时注明出处（标题 · 来源 · 更新时间）。
4. 官方知识全体租户共享（平台超管维护）；本租户知识仅本租户可见——scope=tenant 恒为本租户，由登录身份定域，不要传任何租户参数。
