# 选品报告结构（score-report 四节）

> 来源注记：本结构提炼自 SPE 设计文档 `SPE/docs/2026-09-26-ozon-selection-agent-design.md`（M1 报告风格：score-report 卡片 = 标题 + 若干小节，每节小标题 + Markdown 正文 + 可选要点；小节统计值由后端从所引用数据块现算，模型只负责文字）。

用 generate_report 汇编时，按以下四节成稿，顺序固定：

## 概览

- 回答的问题、检索口径（类目/关键词/价格带/榜单周期）、候选规模与取数链路。
- 一句话给出总体判断（值得跟 / 谨慎 / 回避），依据指向候选对比节。

## 候选对比

- 引用候选表与体检表：小节填 blockId（取法见 SKILL.md——从工具返回 JSON 信封的 blockId 字段取，形如 blk_…），后端会为该节补候选数、均价、销量合计、平均评分等统计值。
- 挑 3–5 个代表 SKU 做文字对比：价格带位置、销量量级、评分表现；有 Jev 评级时点出，本次没有 Jev 评级就如实注明。

## 风险

- 数据局限：榜单周期、缓存时效、样本量、类目口径。
- 供给与竞争风险：头部集中度、价格战迹象、跟卖难度。
- 本次取数的不完整处如实列出（如预算到限、某工具无数据、Jev 缺席）。

## 建议

- 给出明确的跟品/回避结论，逐条配理由；理由里出现的每个数字都必须能在工具回执里找到。
- 下一步动作：换筛选条件再圈一批、等待预算窗口后再试、对重点 SKU 做更深体检。

写作约束：正文写在 bodyMarkdown，要点用 lists（每条一句话）；数字只来自工具回执或后端现算的统计值，禁止编造。
